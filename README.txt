PERSONAL SITE STARTER — VERSION 2

STYLE: Neocities / old-web personality meets Swiss modernist grid design.
Palette: warm paper, near-black ink, electric blue, acid-lime details.
Responsive plain HTML/CSS; no framework or build step.

SETUP
1. Unzip this folder.
2. Upload the CONTENTS of this folder to the root of your GitHub Pages publishing source. index.html must be at the root.
3. Replace First Last, initials, thesis titles, descriptions, university/year, and email.
4. Add your PDFs to papers/ with exact filenames:
   graph-theory.pdf
   econometrics.pdf
   financial-mathematics.pdf
5. Keep your existing CNAME file in the publishing root.
6. Commit and push.

All placeholder text is intended to be edited. The Google Fonts import requires an internet connection; system font fallbacks are included.
GitHub Pages content is public. Check that your thesis PDFs are okay to publish before uploading.
